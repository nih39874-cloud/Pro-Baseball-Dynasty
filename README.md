# 鑽石王朝 / Pro Baseball Dynasty

六隊職棒經營＋橫向 PWA＋第一人稱 3D 棒球遊戲。

## 目前已可執行

- 無需外部套件即可啟動的 WebGL2 真 3D 球場、球員佔位模型、棒球動態軌跡。
- 本機九局練習賽：AI 逐球模擬、打者自由瞄準、虛線球棒、揮棒、長打、保送、三振、得分。
- 投手球種／自由落點／跑條，投球力道由球員體力自動決定。
- 手動 / AI 模式切換在下一打席生效；總教練可在休息區第一人稱走動。
- 野手自動優先判定，雙人接球機會相近時五秒選人；角色手動移動與接球／傳壘指令。
- 主審有小機率誤判，玩家手動控制場上球員時可申請 ABS，播放判讀畫面。
- 本機 GM 版可快轉遊戲年份、回到有存檔的年份、修改六隊練習資金；起始每隊 5 億元。
- 橫向 PWA、MOBA 式觸控 UI、阻止遊戲區域網頁捲動及長按選取。

## 尚未完成（不可當作正式六人連線服務）

- **正式帳號／多人同步**：對應的 Supabase「鑽石王朝」專案尚未建立，不能將原先聊天室指定的密碼寫入公開靜態檔案。
- **真實球員名單與臉型**：目前練習賽使用泛用佔位模型，尚未匯入 2024 全季＋2025/26 新秀與個人 3D 肖像素材。
- **球員全套財務／選秀／FA／60 人保留／32 人季後賽**：目前是資料架構及規則規格，尚無完整可操作後端流程。
- **真正逐動作手動守備／跑壘與裁判重播挑戰**：已有基礎移動及傳球輸入，尚待完整動畫和伺服器判定。
- **七天週期背景自動運轉與對戰權限**：目前本機練習賽不會在頁面關閉後持續執行。

這些未完成項目絕不能宣稱已經正式上線。所有正式賽事結果必須在後端判定；目前前端判定只適合本機練習賽。

## 本機啟動

```bash
python3 -m http.server 4173
# 開啟 http://localhost:4173
```

無 npm 相依套件。需要支援 WebGL2 的 Chrome / Edge / Safari。

## Supabase 配置說明

SQL 草案在 `sql/001_initial_schema.sql`，提供雙聯盟資料隔離、球隊財務、球員、比賽與 RLS。登入使用 Supabase Auth，帳號由服務端建立，前端不硬編任何密碼。請先選擇 Supabase 組織並建立專用專案，再部署 migration、建立所需帳號與伺服器判定 Edge Functions。正式上線前須確認合約、球員姓名/肖像、球場與數據授權。

## 原始碼架構

- `src/main.js`：只初始化並組裝其他模組。
- `src/core/`：狀態、棒球規則、練習賽狀態機。
- `src/graphics/`：WebGL2、球場 3D 幾何、鏡頭。
- `src/controls/`：觸控搖桿／鍵盤操作。
- `src/ui/`：介面及選單。
- `src/platform/`：PWA 與手勢防護。
- `src/backend/`：未來 Supabase Auth 接口。
